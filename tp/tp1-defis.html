1 Écho

read · write · rax en retour

Écrivez le programme echo.asm. Il demande un prénom, le lit au clavier, puis salue la personne :


      $ ./echo
      Ton prénom : Manon
      Bonjour, Manon !

Le prénom affiché est celui qui a été tapé : il n'est pas écrit dans le programme.

Indices
  • L'appel système read porte le numéro 0. Ses arguments : rdi = 0 (le clavier), rsi = l'adresse où ranger le texte, rdx = le nombre d'octets au plus.
  • Pour réserver de la place sans valeur de départ, ajoutez une section .bss : name resb 32 réserve 32 octets (reserve bytes) à l'adresse name.
  • Après syscall, read renvoie dans rax le nombre d'octets lus, saut de ligne compris : 6 pour Manon suivi de Entrée.
  • Le prochain appel écrase rax : copiez d'abord ce nombre dans un registre libre, comme rbx. Retirez-lui 1 pour ne pas afficher le saut de ligne au milieu de la phrase.
  • Trois write suffisent pour la réponse : Bonjour, , le prénom, puis ! avec le saut de ligne.
Pour valider, assurez-vous que…
  • avec Manon, ./echo affiche Bonjour, Manon ! sur une seule ligne ;
  • avec Cosmo, il affiche Bonjour, Cosmo ! sans changer le programme ;
  • votre commit est poussé.

2 Trois chiffres

div · ASCII · écriture en mémoire

Écrivez le programme three.asm. Il calcule 2 × 127, puis affiche le résultat avec ses trois chiffres :


      Code de retour : 254

Chaque chiffre doit venir du calcul. Partez de cette section .data :


      section .data
          msg db "Code de retour : "
          hundreds db "?"
          tens db "?"
          units db "?", 10
          len equ $ - msg
Indices
  • C'est la suite du bonus number.asm, avec une division de plus.
  • 254 divisé par 10 donne 25, reste 4 : le reste est le chiffre des unités. Divisez ensuite 25 par 10 : reste 5 (les dizaines), quotient 2 (les centaines).
  • div rbx divise rdx:rax : remettez rdx à zéro avant chaque division.
Pour valider, assurez-vous que…
  • ./three affiche Code de retour : 254 suivi d'un saut de ligne ;
  • en remplaçant 127 par 100, il affiche Code de retour : 200 ;
  • votre commit est poussé.
